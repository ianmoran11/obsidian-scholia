# Scholia 0.1.22 — Pi / Codex subscription backend

## New

- Use your OpenAI Codex subscription through Pi on your Mac Mini while reading in Obsidian on Android.
- Select **Pi on Mac** in Scholia settings, with a separate bridge URL, access token, Codex model and **Test Connection**.
- Recover from temporary network interruptions using retained jobs and cursor-based polling, without automatically starting duplicate generations.
- Route templates, attached-note context, captures, follow-ups and regeneration through the selected backend. OpenRouter remains the default; there is no automatic paid-provider fallback.

## Safety and reliability

- The private Mac bridge uses authenticated loopback HTTP behind Tailscale HTTPS. OpenAI credentials remain on the Mac.
- Pi sessions have no tools, personal extensions, project instructions or persistent conversation history. Only Codex subscription authentication is accepted.
- Cancellation, deadlines, shutdown and plugin unload stop pending work. Changed-note checks prevent delayed output from overwriting unrelated edits or another note.
- Usage metadata distinguishes subscription usage from API-price estimates; monetary cost is reported as unavailable.

## Upgrading with BRAT

Run BRAT's update check for `ianmoran11/obsidian-scholia`. This stable release includes `manifest.json` (version `0.1.22`), `main.js`, and `styles.css`. Minimum Obsidian version remains `1.5.0`; Android is supported.

**The Mac bridge is a separate setup, not installed by BRAT.** Follow the [versioned bridge setup guide](https://github.com/ianmoran11/obsidian-scholia/blob/0.1.22/bridge/README.md). It requires Node.js 22.19+, Pi Codex login, a bridge token and private Tailscale connectivity. The bridge package is versioned alongside the plugin at `0.1.22`.

Existing OpenRouter settings are preserved. For Pi, remove OpenRouter-specific template `model:` overrides or use `openai-codex/<model-id>`.

## Current limits

- Pi uses fixed medium reasoning; OpenRouter temperature and output-token-budget overrides are not applied.
- Jobs survive a temporary phone disconnection, not Obsidian process termination or a Mac bridge restart. Results expire ten minutes after completion.
- The Mac must be awake and reachable. Runs consume your Codex subscription allowance.
- Live Android/Tailscale/OAuth behavior requires the manual smoke checklist in the setup guide; it has not been device-tested for this release.

## Validation

242 plugin tests and 16 bridge tests pass, along with both TypeScript checks, production builds and launchd plist validation. Automated bridge tests use synthetic credentials and a fake generation engine, not subscription requests.
